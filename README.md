# 我的 AI 产品作品集

我是代梦，人工智能 专业，目标岗位是 AI 产品经理。
我在科大讯飞教育 BG 实习，画过产品原型。
我做过 2 个深度 AI 产品项目，写过 Badcase 评测，设计过防幻觉规则。
我最擅长的事：把大模型能力翻译成用户能用的产品，并且确保它不说谎。
